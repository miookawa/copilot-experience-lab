# 既存資料を要約する｜CHAT-18

| 項目 | 内容 |
|---|---|
| **目的** | 読む必要のある資料を、説明できる状態まで一気に引き上げる |
| **所要** | 約 10 分（目安） |
| **利用** | Microsoft Copilot Chat（Work） ／ Word の Copilot |
| **入力** | 実際に読む必要がある Word / PDF / PowerPoint 1 点 |
| **成果** | 3 行要約、重要な主張、意思決定点、前提・制約、確認点、5 分で話す順番 |

> **実施条件**：Microsoft Copilot のライセンスがあり、自分のメール・会議・ファイルにアクセスできる場合にハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

---

## シナリオ

Week 3 のテーマは、**ゼロから作る仕事を減らす**ことです。まずは「読む」から始めます。

架空の資料ではなく、実際に読まなければならない資料を指定します。要約で終わらせず、「5 分で説明する場合の話す順番」まで出させるのがポイントです。

> 進行役の説明例：「要約を読む日ではなく、その資料を人に説明できる状態になる日です。」

---

## TRY — 手順

1. 実際に読む必要がある Word、PDF、PowerPoint を 1 点選ぶ
2. Copilot Chat を開き、そのファイルを参照として指定する
3. プロンプト ボックスをクリックする
4. 次のプロンプトを貼り付ける

```text
この資料を、初めて読む人向けに整理してください。

- 3行要約
- 重要な主張
- 意思決定が必要な点
- 前提または制約
- 確認すべき点
- 5分で説明する場合の話す順番
```

5. **送信**を選ぶ
6. 3 行要約が資料の主旨と合っているかを確認する
7. 「意思決定が必要な点」が本当に未決事項かを確認する
8. 資料の該当箇所を開いて裏を取る
9. 「5 分で説明する順番」に沿って、実際に声に出して説明してみる
