# 競合3社のメモを比較表と示唆に変える｜CHAT-01

| 項目 | 内容 |
|---|---|
| **目的** | 断片的な競合メモを、会議で使える構造化された比較表と示唆に変える |
| **所要** | 約 10 分（目安） |
| **利用** | Copilot Chat |
| **入力** | 競合 3 社のメモ（下記プロンプトに含む） |
| **成果** | 比較表 ＋ ポジショニングの示唆（3〜4 文） |

---

## シナリオ

**曽根拓海さん** は Spring Outdoor ローンチを担当する商品企画部長です。
今日の午後にディレクターとの 1on1 を控えており、競合アウトドア アパレル 3 ラインの状況をすばやく把握しておく必要があります。

ブラウザーのタブをいくつも開いて手作業で比較表を組み立てる代わりに、Copilot Chat で**項目を整理した競合比較と、会議でそのまま使える短い示唆**を作ります。

> 進行役の説明例：「曽根さんは会議の前に競合 3 社を比べたいだけです。長い調査プロジェクトは要りません。会話に使える、整理された比較情報が欲しいのです。」

---

## TRY — 手順

1. Copilot Chat で **新しいチャット**（または `+` アイコン）を選ぶ
2. プロンプト ボックスをクリックする
3. 次のプロンプトを貼り付ける

```text
以下の競合メモを使って、2026 年春向けのアウトドア アパレル 3 ラインを比較してください。
追加の企業情報は検索しないでください。提供された情報のみを使ってください。

競合メモ:

アドベンチャーワークス
主力商品: トレイルレディ ウインドブレーカー
価格帯: 12,591〜18,967 円
ターゲット顧客: 軽量で実用的なレイヤリングを求める、アクティブなファミリー層とカジュアルな週末サイクリスト
最近のマーケティング訴求: 日常的なアウトドアへの備え、柔軟なレイヤリング、家族での週末利用

アルパインスキーハウス
主力商品: アルパインストーム シェル
価格帯: 23,749〜39,688 円
ターゲット顧客: 技術的な性能と防護性能を重視するアウトドア愛好家
最近のマーケティング訴求: プレミアムな防護性、技術的な耐久性、サステナビリティに裏打ちされた素材

ボルダーイノベーションズ
主力商品: テラフレックス パンツ
価格帯: 14,185〜20,561 円
ターゲット顧客: 汎用性の高いアウトドア アパレルを求める、価格を重視するハイカーとアクティブな通勤者
最近のマーケティング訴求: 賢いバリュー、リサイクル素材、動きやすさ、一日中続く快適さ

次の列を持つ比較表を返してください:
ブランド、主力商品、価格帯（円）、ターゲット顧客、最近のマーケティング訴求。

表の下に、今年これらのブランドがスプリングアウトドアをどうポジショニングしているかについて、
特筆すべき点を 3〜4 文の段落で書いてください。
```

4. **送信**を選ぶ
5. 比較表を確認する
6. 表の下の示唆の段落を確認する
7. Copilot がラフなメモを、ビジネスで使える構造化サマリーに変えたことに注目する

## REFLECT — 振り返り

- 生のメモと比べて、この出力は何が使いやすかったか
- プロンプトに「出典を明示した情報」と「出力の構造指定」が含まれていた点に注目する
- 自分の業務で、同じ形に置き換えられる「バラバラの情報」は何か

**押さえるポイント**
- プロンプトに明確な元情報が含まれている
- 出力の構造を指定している
- Copilot はメモを、そのまま使えるビジネス サマリーに変える

**利用できない場合の進め方**
ファシリテーターの端末でプロンプトを実行し、参加者には出力の「構造」に注目してもらいます。
