# 顧客クレームを論点整理し返信案まで作る｜CHAT-03

| 項目 | 内容 |
|---|---|
| **目的** | 感情的な長文クレームから論点を切り出し、選択肢を比較し、共感的な返信案までを一気に作る |
| **所要** | 約 10 分（目安） |
| **利用** | Copilot Chat |
| **入力** | 顧客からのクレーム メール（下記に含む） |
| **成果** | 論点リスト ＋ 解決オプション 2 案とトレードオフ ＋ 150 語未満の返信ドラフト |

---

## シナリオ

**遠藤淳也さん** は Lakeshore Retail のカスタマーサポート責任者です。
アウトドア家具の配送遅延について、不満を募らせた顧客から長文のクレームが届きました。昼までに同種のメッセージをいくつも確認しなければなりません。

読む・仕分ける・選択肢を比べる・返信を書く、をバラバラにやる代わりに、Copilot Chat で**論点抽出 → 解決オプション提示 → 共感的な返信案作成**を一つの流れで行います。

> 進行役の説明例：「このクレームには、不満、連絡不足、緊急性、顧客との関係リスクが混ざっています。これは単なる文章作成ではなく、**対応の優先順位と方針を整理する作業**です。」
> 「Copilot に 3 つのことを頼んでいます。論点を抽出する、選択肢を検討する、返信を書く、です。」

---

## TRY — 手順

1. Copilot Chat で新しいチャットを開始する
2. プロンプト ボックスをクリックする
3. 次の顧客メールを貼り付ける

```text
こんにちは。正直、もう我慢の限界なので連絡しています。3 週間前に御社のウェブサイトで
アウトドア用ソファセットを注文しました。当初の配送予定日は、何の連絡もないまま過ぎました。
火曜日に電話したところ、「5 営業日以内には配送される」と言われました。それも過ぎました。
今週の土曜日には来客の予定があるのに、庭は空っぽのままです。何年もレイクショアを使ってきましたが、
自分の存在が見えていないと感じたのは初めてです。誰かが本当にこの件を引き受けるべきです。
- 佐藤 大輔
```

4. メールの下に、次の指示を貼り付ける

```text
この顧客メールを読んで、次の 3 つを行ってください。

1- 顧客が提起している具体的な問題点を、箇条書きで抽出してください。
2- 提示できる解決オプションを 2 つ、それぞれのトレードオフとともに提案してください。
3- 2 つのうち有力な方を選び、それを提示する共感的な返信を 150 語未満で作成してください。
```

5. **送信**を選ぶ
6. 抽出された論点リストを確認する
7. 2 つの解決オプションとトレードオフを確認する
8. 顧客向け返信ドラフトを確認する

### 発展（任意）

ファシリテーターの指示があれば、後半でファイルを使ったバージョンを試します。
`customer-complaint-cases.xlsx` を使い、クレームのテーマ、優先度の高い課題、推奨対応アクションを特定します。
これは任意であり、本演習の必須要素ではありません。

## REFLECT — 振り返り

- Copilot は「感情的なメッセージ」と「オペレーション上の課題」を切り分けている
- 応答には文面だけでなく、**選択肢とトレードオフ**が含まれている
- 何を送るかを決め、レビューするのは依然として人間である
- 送信前に自分なら何を直すか

**利用できない場合の進め方**
その場でプロンプトを実行するか、事前に用意した応答を見せ、「送信前に何を調整するか」を参加者に問いかけます。
