# 自社ファイルを根拠に競合分析を自社視点へ引き上げる｜CHAT-06

| 項目 | 内容 |
|---|---|
| **目的** | 一般的な競合サマリーから、自社にとっての意味を語る提言へ引き上げる |
| **所要** | 約 10 分（目安） |
| **利用** | Microsoft 365 Copilot Chat（Work） |
| **入力** | **サンプル ファイル**：[`lakeshore-prior-season-strategy.docx`](https://github.com/miookawa/copilot-experience-lab/releases/download/lakeshore-sample-data-ja-v1.0.0/lakeshore-prior-season-strategy.docx)、[`lakeshore-brand-playbook.docx`](https://github.com/miookawa/copilot-experience-lab/releases/download/lakeshore-sample-data-ja-v1.0.0/lakeshore-brand-playbook.docx) |
| **成果** | 競合比較表 ＋ レイクショア固有のポジショニング提言（4〜5 文） s3 |

> **実施条件**：Microsoft 365 Copilot とレイクショアのファイルにアクセスできる場合のみハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

---

## シナリオ

**曽根拓海さん**はレイクショア（架空の小売企業）の商品企画部長です。
同じ競合 3 社を一般情報だけで比較する [CHAT-01](./CHAT-01_競合3社のメモを比較表と示唆に変える.md) に、レイクショアの社内文書を加えて分析を深めます。
今回必要なのは、競合の一般的な状況ではなく、**その状況がレイクショアにとって何を意味するか**です。

レイクショアの前シーズン戦略とブランド プレイブックを使うことで、Microsoft 365 Copilot は
「一般的な競合サマリー」から「自社固有のビジネス提言」へと進みます。

> 進行役の説明例：「一般的な競合比較にレイクショアの社内情報を加え、自社にとって意味のある提言へ引き上げます。」

---

### サンプルファイルの準備

入力欄の 2 ファイルが OneDrive または SharePoint に準備済みなら、そのまま TRY に進んでください。
まだ準備していない場合は、入力欄のリンクからファイルをダウンロードし、OneDrive または SharePoint にアップロードします。レイクショアのサンプルデータ一式を準備する場合は、[SETUP-01](../00-setup/SETUP-01_サインイン確認と安全なAI利用の土台づくり.md) の手順を参照してください。

---

## TRY — 手順

1. Copilot Chat を開く
2. **Work** が選択されていることを確認する
3. レイクショアのファイルが OneDrive または SharePoint にあることを確認する
4. プロンプト ボックスをクリックする
5. 次のプロンプトを貼り付ける

```text
2026 年春向けに、競合のアウトドア アパレル 3 ライン
（アドベンチャーワークス、アルパインスキーハウス、ボルダーイノベーションズ）を比較してください。

次の列を持つ比較表を返してください:
ブランド、主力商品、価格帯（円）、ターゲット顧客、最近のマーケティング訴求。

そのうえで、lakeshore-prior-season-strategy.docx と lakeshore-brand-playbook.docx を使い、
これらのブランドの春のポジショニングがレイクショアのポジショニングに具体的にどう影響するかを
4〜5 文の段落で書いてください。どこで攻めるべきか、どこで差別化すべきか、
そして前シーズンの結果から「繰り返すべきでない」ことは何かを含めてください。
```

6. **送信**を選ぶ
7. 競合比較表を確認する
8. レイクショア固有の提言の段落を確認する
9. 戦略文書とブランド プレイブックへの参照があるかを探す
10. 引用元やソース参照を、表示されていれば開いてみる
