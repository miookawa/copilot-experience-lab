## 「この案件、進めていい？」をCoworkに調査させる｜CWK-09

| 項目 | 内容 |
|---|---|
| **目的** | 会議、メール、チャット、提案資料などに分散した意見を Cowork に横断調査させ、賛成・反対・懸念・未解決論点と利害関係者マップを含む、意思決定用の合意形成ブリーフを 1 回の依頼で作成する |
| **所要** | 約 30 分（目安／Cowork の処理時間を含む） |
| **利用** | Microsoft 365 Copilot Cowork（会議、メール、Teams、OneDrive / SharePoint 上の Word・PowerPoint・PDF など、利用環境でアクセス可能な業務データ） |
| **入力** | **自分の業務データ**：同じ導入テーマに関する会議記録、メール、チャット、提案書、検討資料、FAQ など |
| **成果** | 経営判断用の合意形成ブリーフ → 賛成・反対・懸念・未解決論点 → 利害関係者マップ → 合意形成の阻害要因 → 推奨アクション → 根拠一覧 |


**実施条件**：Copilot Cowork から、演習に使用する会議、メール、チャット、ファイルなどへアクセスできる場合のみハンズオンで実施します。アクセスできない情報源は調査対象から除外されます。対象データに機密情報や個人情報が含まれる場合は、組織のルールに従って取り扱ってください。

**演習データの推奨条件**：1 つの導入テーマに絞り、異なる立場の意見が含まれる複数の情報源を用意します。たとえば、経営層、IT、セキュリティ、法務、利用部門などの期待や懸念が確認できるデータです。

**クレジット消費の目安**：Heavy（[要記入]〜[要記入] クレジット）。この演習の参考区分です。実際の消費量は、対象データの量・形式・内容、探索範囲、作成する成果物によって変動します。Light / Medium / Heavy の区分は、Microsoft の [Copilot Credits Guide](https://www.microsoft.com/licensing/guidance/Copilot-Credits) で使われている表現に基づきます。

### シナリオ

Copilot や AI エージェントなど、新しい仕組みの導入を進める際、社内の意見は一つの資料にまとまっているとは限りません。経営層は投資効果、IT 部門は運用、セキュリティ部門は統制、利用部門は業務効果や教育負荷を重視するなど、期待と懸念が会議、メール、チャット、提案資料に分散しています。

人が合意形成ブリーフを作る場合、関連情報を探し、資料を読み、発言を比較し、対立点を特定し、関係者ごとの期待や懸念を整理したうえで、次のアクションを考える必要があります。

この体験では、その一連の仕事を細かな質問に分解しません。Cowork に目的と完成条件を一度伝え、関連情報の探索、横断分析、利害関係者マップの作成、阻害要因の特定、推奨アクションの提案、意思決定用ブリーフの作成までをまとめて任せます。

**演習のポイント**：完成した文章のきれいさだけでなく、Cowork が複数の情報源をたどり、異なる立場の意見を関連付け、根拠を示しながら一つの業務成果へまとめる過程に注目してください。

**進行役の説明例**：「Copilot に順番に質問して資料を組み立てるのではなく、今日は『社内合意形成に必要な調査と整理を完了し、役員向けブリーフに仕上げる』という仕事全体を Cowork に一度で任せます。」

### TRY — 手順

#### 1. 導入テーマと対象範囲を決める

次のような、社内で複数の立場が関わるテーマを 1 つ選びます。

- Microsoft 365 Copilot の全社展開
- AI エージェントの業務導入
- 新しい CRM / ERP の導入
- 社内データ活用基盤の導入
- 新しいセキュリティ施策の導入

対象期間、対象組織、関連するプロジェクト名が分かる場合は、プロンプト内の `[ ]` に入力します。

#### 2. 利用する情報を確認する

- Cowork からアクセスできる会議、メール、Teams、OneDrive / SharePoint 上のファイルを確認する
- 演習対象の情報を分析してよいことを確認する
- 機密情報や個人情報の取り扱いが組織のルールに沿っていることを確認する
- サンプルデータを使用する場合は、推進、慎重、反対、判断保留など、複数の立場が含まれていることを確認する

#### 3. Cowork に仕事全体を一度で依頼する

Copilot Cowork を開き、次の `[ ]` を置き換えてプロンプトを送信します。

> 例えば、"[ここ1〜3か月の] の [AI エージェントの業務導入] について

```text
[対象期間] の [プロジェクト名] について、
この案件を進めるべきか判断するための調査を実施し、
役員向けの判断ブリーフを作成してください。

会議、メール、Teams、関連資料を横断して調査し、

・期待される効果
・賛成意見
・反対意見
・懸念事項
・未解決論点
・利害関係者マップ
・推奨アクション

を整理してください。

また、今決められること、
決定前に追加確認が必要なことを分けて示してください。

不明な情報は推測せず、
確認できないと明記してください。
```

#### 4. 調査中の動きを観察する

Cowork が処理を進める間、次の点を確認します。

- 関連する情報源を複数の場所から探索しているか
- 依頼を複数の作業に分けて進めているか
- 単なる検索結果の列挙ではなく、比較や関連付けを行っているか
- 結果を指定した業務成果物にまとめているか

> 注：実際に表示される処理内容や確認メッセージは、環境、アクセス権、対象データ、製品の状態によって異なります。

#### 5. 成果物を確認する

生成された合意形成ブリーフについて、次を確認します。

- 賛成、反対、懸念、判断保留が区別されているか
- 利害関係者マップに、期待、懸念、影響力、必要な働きかけが含まれているか
- 発言や立場を推測せず、根拠に結び付けているか
- 情報源間の一致点と食い違いが示されているか
- 合意形成の阻害要因が具体化されているか
- 未解決論点と不足情報が明示されているか
- 「今決められること」と「確認後に決めること」が分かれているか
- 推奨アクションが、誰に対する何の働きかけか分かる形になっているか

#### 6. 根拠を人が確認する

- 重要な主張を最低 2 件選ぶ
- 示された会議、メール、チャット、ファイルの該当箇所を開く
- ブリーフの記述が元情報に沿っているか確認する
- 根拠が弱い分類、実際より強い表現、立場の誤認がある場合は修正する
- 最終版を意思決定用のブリーフとして保存する

必要な場合だけ、次の短い追加依頼で修正します。

```text
根拠を確認したところ、[修正したい箇所] は [確認結果] でした。
該当箇所と、それに依存する利害関係者マップ、阻害要因、推奨事項を修正してください。
それ以外の構成は維持してください。
```

### Copilot との体験の違いを確認する

この演習の比較ポイントは、単に「複数の情報を要約できるか」ではありません。

**Copilot を順番に使う場合の例**

1. 関連する会議を探す
2. 会議を要約する
3. 関連メールを探す
4. 資料を読み込ませる
5. 賛否を分類する
6. 利害関係者マップを作る
7. 未解決論点を整理する
8. 役員向けブリーフへ書き直す

**この Cowork 体験**

- ユーザーは、目的、調査対象、完成条件を 1 回で伝える
- Cowork に、探索、比較、分析、構造化、成果物作成までの仕事全体を任せる
- ユーザーは、手順の指示者ではなく、仕事の依頼者と確認者になる

**体験後に持ち帰ってほしいメッセージ**

> Copilot に作業を一つずつ手伝ってもらうのではなく、Cowork に「社内合意形成に必要な調査を終え、意思決定用の成果物にする」という仕事全体を任せる。

### REFLECT — 振り返り

- 1 回の依頼から、関連情報の探索、分析、利害関係者マップ、ブリーフ作成まで進められたか
- 自分で会議、メール、チャット、ファイルを順番に探す手数はどれだけ減ったか
- 個別の資料だけでは気付きにくい、立場の違い、一致点、食い違いを発見できたか
- 利害関係者マップは、誰と何を話すべきかを判断する材料になったか
- 「今決められること」と「確認後に決めること」を区別できたか
- Cowork に仕事を任せるために、目的、対象範囲、完成条件のうち何を明確にする必要があったか
- 最終判断の前に、人が確認すべき根拠は何だったか

#### うまく動かない場合

- 関連情報が見つからない場合は、対象期間、導入テーマ、プロジェクト名、組織名を具体化してください。
- 対象が広すぎる場合は、期間または対象組織を絞ってください。
- 利害関係者マップが抽象的な場合は、関係部門をプロンプト内に明記してください。
- 立場の分類に根拠がない場合は、推測による分類を削除し、「確認できない」に変更してください。
- 情報源の提示が不十分な場合は、重要な主張ごとに会議名、メール件名、ファイル名などを示すよう修正してください。
- 一部の情報源へアクセスできない場合は、アクセス可能なサンプルデータに対象を限定してください。

### 注意事項

- 利害関係者マップは、人の感情、性格、意図、能力を評価するものではありません。業務上の情報源に明示された期待、懸念、発言、決定事項だけを整理してください。
- 情報源が古い場合、現在の立場と一致しない可能性があります。重要な判断の前に、該当する関係者へ確認してください。
- Cowork が示した根拠や分類の正確性が自動的に保証されるわけではありません。重要な主張は人が元情報で確認してください。
- 契約、法務、財務、セキュリティ、コンプライアンスなど、専門的判断が必要な事項は、該当分野の専門家に確認が必要です。
