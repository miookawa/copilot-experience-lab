## 売上データを渡したら、役員会資料まで出来ていた。｜CWK-11

| 項目 | 内容 |
|---|---|
| **目的** | 売上データを渡すだけで、根拠を確認できる分析用 Excel と、承認を得るための役員会用 PowerPoint を、数字と結論が一致した状態で同時に用意する |
| **所要** | 約 45 分（目安／Cowork の処理時間を含む） |
| **利用** | Microsoft 365 Copilot Cowork（Excel / PowerPoint / Web 検索） |

## シナリオ

あなたは、アパレルメーカー兼小売企業 **TrendStyle Japan**（架空の企業です）の経営企画部長です。

明日の役員会で、次の 3 点を決める必要があります。

- どの商品カテゴリへ投資するか
- どの地域を強化するか
- 新規出店候補をどこまで検証するか

手元にあるのは、2,160 行の販売明細と市場データが入ったブック 1 冊と、前年の役員会資料 1 式だけです。

これまでは、Excel を開いて分析し、集計表とグラフを作り、結果を整理し、PowerPoint を開いて内容を引き継ぎ、スライドを作り、最後に両者の数字が食い違っていないかを確認する、という工程を人が順番に進めていました。

この体験では、**1 回の依頼で、分析用 Excel と役員会用 PowerPoint を同時に作らせます**。さらに、短い追加指示だけで両方のファイルが連動して更新されることを確認します。

> **演習のポイント**：「2 つのファイルができた」ことではなく、**Excel の分析結果と PowerPoint の主張が一致していること**、そして**一言の修正指示で両方が同時に直ること**に注目してください。

> **進行役の説明例**：「Copilot は、Excel の中で分析を助け、PowerPoint の中で資料作成を助けます。Cowork には『役員会の準備を完了して』と、仕事全体を渡せます。」

## TRY — 手順

1. Copilot Cowork を開き、`TrendStyleJapan-SalesData.xlsx` と `TrendStyleJapan_2025年度_役員会資料テンプレート.pptx` を添付する
2. 次のプロンプトを貼り付ける

```text
添付の売上データと前年の役員会資料を使って、
明日の役員会の準備を完了してください。

1. 分析用Excel
カテゴリ別・地域別の売上、前年比成長率、粗利額、粗利率を整理し、
成長率×粗利率×売上規模を比較できるチャートを付けてください。
各カテゴリを「拡大投資」「収益改善を条件に投資」「維持」「縮小検討」に分類してください。

2. 役員会用PowerPoint
前年資料のスタイルで、経営サマリー、商品ポートフォリオ、重点地域、
新規出店候補、主なリスク、次の90日、承認してほしい事項をまとめてください。

数字と結論は、ExcelとPowerPointで一致させてください。
確認できないことは推測で埋めず、追加確認事項として示してください。
```

3. **送信**を選ぶ（処理には数分かかります）
4. 処理中の表示を見る。売上データの確認 → 市場データの確認 → 前年資料の参照 → 集計 → 投資候補の比較 → Excel 作成 → PowerPoint 作成 → 両者の整合、と**工程が順番に進むこと**を全員で確認する
5. 生成された Excel を開き、次を確認する
   - カテゴリ別・地域別の売上、成長率、粗利率が整理されているか
   - 成長率 × 粗利率 × 売上規模を比較できるチャートがあるか
   - 投資分類の根拠が示されているか
6. 生成された PowerPoint を開き、次を確認する
   - 前年資料の色、フォント、レイアウトが引き継がれているか
   - 承認してほしい事項が明示されているか
   - **元の Excel にない数値が追加されていないか**
7. **売上規模 1 位のカテゴリの扱いを確認する**。売上構成比も成長率も 1 位のカテゴリが粗利率では最下位、という状態がこのデータには含まれています。「拡大投資」ではなく「収益改善を条件に投資」となっているか、Excel と PowerPoint の両方で確認する

### (オプション) 短い追加指示で、両方を同時に直す

8. 次の 3 つを、1 つずつ順番に送信する

```text
CFOから反対意見が出る前提で、想定質問と回答を追加して。
```

```text
投資額を決める資料ではなく、投資条件を決める資料に直して。
```

```text
役員が確認すべき数字をExcelで目立たせ、PowerPointの結論も合わせて更新して。
```

9. **1 つの短い指示で、Excel と PowerPoint の両方が更新されること**を確認する
10. 最後に、Excel の数字と PowerPoint の結論が食い違っていないかを 1 か所だけ照合する

> **注意**：生成された数値、分類、チャート、スライドの主張は、人が確認してください。投資や出店の最終判断には、財務、市場調査、店舗開発などの専門家への確認が必要です。

## REFLECT — 振り返り

- 今回、あなたが自分で操作したアプリはいくつでしたか。Cowork が代わりに進めた工程はいくつありましたか
- Excel の分析結果と PowerPoint の主張は一致していたか。ずれていた場合、どこがずれていたか
- 短い追加指示で両方が更新されたとき、手作業なら何を直す必要があったか
- 売上 1 位のカテゴリを「拡大投資」と断定しなかったか。断定していた場合、どう指示すれば直ったか
- Cowork が「確認できない」とした項目は、役員会で本当に必要な情報だったか
- 同じ進め方を、月次報告、予算策定、事業計画レビューに応用できるか

### うまく動かない場合

- 2 ファイルが同時に作られない場合は、「まず分析用 Excel を作ってください」「次に、その Excel を基に役員会用 PowerPoint を作ってください」と 2 回に分けて依頼してください。
- PowerPoint に前年のデザインが反映されない場合は、テンプレートを添付し直し、「前年資料のテーマとレイアウトをそのまま使ってください」と明示してください。
- Excel にない数値が資料に現れた場合は、該当スライドを指定し、「元データにない数値を削除し、追加確認事項に移してください」と指示してください。
- 処理が長い場合は、対象を商品カテゴリまたは地域のどちらか一方に絞ってください。
