# プロジェクトを締めくくり、関連する作業をすべて整理する｜CWK-02

| 項目 | 内容 |
|---|---|
| **目的** | 散らばったファイルの痕跡ではなく、整理された共有可能なアーカイブと振り返りページでプロジェクトを閉じる |
| **所要** | 約 20 分（目安） |
| **利用** | Microsoft 365 Copilot Cowork（OneDrive / SharePoint） |
| **入力** | **自分の業務データ**：終了した、または区切りのついたプロジェクト 1 件と、その関連ファイル |
| **成果** | アーカイブ フォルダー（関連ファイルを集約）→ 共有設定 → HTML の振り返りページ 1 枚 |

> **実施条件**：Copilot Cowork から自分の OneDrive / SharePoint にアクセスできる場合のみハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

> **クレジット消費の目安**：`[Light / Medium / Heavy から選択]`（`[要記入]〜[要記入]` クレジット）。この演習の手順を実行した場合の参考値です。実際の消費量は、対象データの量・形式・内容や、依頼する処理によって変動します。
>
> Light / Medium / Heavy の区分は、Microsoft の [Copilot Credits Guide](https://www.microsoft.com/licensing/guidance/Copilot-Credits) で使われている表現に基づきます。

---

## シナリオ

プロジェクトが一区切りついたときは、まず、積み重ねてきた仕事と、そこから生まれた成果を喜びたいものです。
けれど、次の仕事へ気持ちよく進むためには、散らばったファイルを探して整理し、共有設定を整え、最後に「何をリリースしたのか」を誰かに説明できる形で残す必要があります。
どれも大切な締めくくりですが、思った以上に時間がかかり、「抜け漏れがないか」という不安も残りがちです。

この体験では、1 回の依頼で、**特定 → 分類 → フォルダー作成 → コピー → 共有 → 振り返りページ作成**までを Cowork に任せます。
あなたの役割は、作業者からレビュー役に変わります。

> **演習のポイント**：成果物は 2 つあります。「整理されたフォルダー」と「HTML の振り返りページ」です。
> 後者は Word でも PowerPoint でもなく **HTML** で出てくることに注目してください。リンクを送るだけで誰でも辿れる、Cowork らしい成果物の形です。

> **進行役の説明例**：「ファイル整理は Copilot に頼む仕事ではない、と思っていた方ほど今日は見てください。整理だけでなく、整理した結果を説明する 1 枚まで出てきます。」

---

## TRY — 手順

1. 区切りのついたプロジェクトを 1 件決める（機密性の高い案件は避けてください）
2. Copilot Cowork を開き、次のプロンプトを貼り付ける
   - `[プロジェクト名]` を自分のプロジェクト名に置き換えます
   - アーカイブ フォルダーを `[プロジェクト名]` チームに共有して問題がないことを確認してから進めます

```text
[プロジェクト名] プロジェクトが完了しました。

本プロジェクトに関連する OneDrive 上のすべてのファイル
（ドキュメント、デッキ、スプレッドシート）を特定してください。

「[プロジェクト名] — アーカイブ」という新規フォルダーを作成し、
該当ファイルをその中にコピーしてください。
整理された参照先になるよう、そのアーカイブフォルダーを
[プロジェクト名] チームへ共有してください。

次に、アーカイブ用の軽量な HTML 振り返りページを作成してください。
プロジェクトの成果、主要な貢献者、注目すべき成果物へのリンク、
そして冒頭に「何をリリースしたか」を 1 段落でまとめた要約を置き、
単なるファイルの集まりではなく、
辿りやすいアーカイブになるようにしてください。
```

3. **送信**を選ぶ
4. OneDrive 側でアーカイブ フォルダーが作成され、ファイルがコピーされていることを確認する。元の場所にもファイルが残っていることを確認する
5. 生成された HTML ページを開き、**事実と異なる記述がないか**を必ず確認する

> **プライバシーに関する注意**：共有設定を行う前に、アーカイブに機密情報を含むファイルが入っていないかを必ず確認してください。
> `[プロジェクト名]` チームへの共有が適切でない場合は、この演習では共有を行わないでください。

## REFLECT — 振り返り

- Cowork が「関連ファイル」と判断した根拠は妥当だったか。人の目で見て漏れていたのはどれか
- 普段、同じ作業を手作業で行うとしたら、どの工程に最も時間がかかるか
- 1 回の依頼からファイルの特定、アーカイブ作成、振り返りページ作成まで進んだことで、手作業はどれだけ減ったか
- HTML の振り返りページは、そのまま人に送れる品質だったか。足りなかったのは何か

**うまく動かない場合**
ファイルが特定されない場合は、プロジェクト名だけでなく、関係者名・期間・キーワードをプロンプトに追加してください。
コピーが実行されない場合は、対象ファイルが他者所有の SharePoint ライブラリにないか（自分に編集権限があるか）を確認してください。
