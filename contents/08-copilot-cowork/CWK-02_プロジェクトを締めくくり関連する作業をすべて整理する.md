# プロジェクトを締めくくり、関連する作業をすべて整理する｜CWK-02

| 項目 | 内容 |
|---|---|
| **目的** | 散らばったファイルの痕跡ではなく、整理された共有可能なアーカイブと振り返りページでプロジェクトを閉じる |
| **所要** | 約 20 分（目安） |
| **利用** | Microsoft 365 Copilot Cowork（OneDrive / SharePoint） |
| **入力** | **自分の業務データ**：終了した、または区切りのついたプロジェクト 1 件と、その関連ファイル |
| **成果** | アーカイブ フォルダー（関連ファイルを集約）→ 共有設定 → HTML の振り返りページ 1 枚 |

> **実施条件**：Copilot Cowork から自分の OneDrive / SharePoint にアクセスできる場合のみハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

> **クレジット消費の目安**：70〜200 クレジット程度。この演習の手順を実行した場合の参考値です。実際の消費量は、対象データの量・形式・内容や、依頼する処理によって変動します。

---

## シナリオ

プロジェクトが終わったとき、あなたがやっているのはたいてい単純作業です。
散らばったファイルを探し、フォルダーを作り、移し、共有設定をし、最後に「何をリリースしたのか」を誰かに説明できる形で残す。
価値はあるのに、時間だけが削られ、しかも「抜け漏れがないか」という不安は最後まで消えません。

この体験では、**特定 → 分類 → フォルダー作成 → 移動 → 共有 → 振り返りページ作成**までを Cowork にひと続きで任せます。
あなたの役割は、作業者からレビュー役に変わります。

> **演習のポイント**：成果物は 2 つあります。「整理されたフォルダー」と「HTML の振り返りページ」です。
> 後者は Word でも PowerPoint でもなく **HTML** で出てくることに注目してください。リンクを送るだけで誰でも辿れる、Cowork らしい成果物の形です。

> **進行役の説明例**：「ファイル整理は Copilot に頼む仕事ではない、と思っていた方ほど今日は見てください。整理だけでなく、整理した結果を説明する 1 枚まで出てきます。」

---

## TRY — 手順

### パート 1 — 対象を決め、洗い出させる

1. 区切りのついたプロジェクトを 1 件決める（機密性の高い案件は避けてください）
2. Copilot Cowork を開き、次のプロンプトを貼り付ける
   - `[プロジェクト名]` を自分のプロジェクト名に置き換えます

```text
[プロジェクト名] プロジェクトが完了しました。

本プロジェクトに関連する OneDrive 上のファイル（ドキュメント、デッキ、スプレッドシート）を
すべて特定し、一覧にしてください。

各ファイルについて、ファイル名、種類、最終更新日、そして「なぜこのプロジェクトに
関連すると判断したか」を示してください。

この時点ではまだファイルを移動しないでください。
```

3. **送信**を選ぶ
4. 一覧を確認する。**入っているべきなのに入っていないファイル**、**入るべきでないファイル**がないかを見る

### パート 2 — アーカイブを作らせる

5. 続けて、次のプロンプトを貼り付ける
   - `[共有相手]` は、同じ演習に参加しているメンバーなど、共有して問題のない相手に置き換えます
   - 適切な共有相手がいない場合は、プロンプト末尾の共有に関する一文を削除します

```text
一覧のうち、[除外したいファイルがあればここに記載] を除いて進めてください。

「[プロジェクト名] — アーカイブ」という新規フォルダーを作成し、該当ファイルをその中に
移動してください。移動する前に、移動対象の最終リストを見せて私の承認を取ってください。

承認後、整理された参照先になるよう、そのアーカイブ フォルダーを [共有相手] へ共有してください。
```

6. **送信**を選ぶ
7. 最終リストを確認し、承認する
8. OneDrive 側でフォルダーが作成され、ファイルが移動していることを確認する

### パート 3 — 振り返りページを作らせる

9. 続けて、次のプロンプトを貼り付ける

```text
次に、アーカイブ用の軽量な HTML 振り返りページを作成してください。

含めるもの:
・冒頭に「何をリリースしたか」を 1 段落でまとめた要約
・プロジェクトの成果（定量的なものがあれば数字で）
・主要な貢献者
・注目すべき成果物へのリンク

単なるファイルの集まりではなく、後から来た人が辿れるアーカイブにしてください。
事実として確認できない内容は書かず、不明な点は「要確認」と明記してください。
```

10. **送信**を選ぶ
11. 生成された HTML ページを開き、**事実と異なる記述がないか**を必ず確認する

> **プライバシーに関する注意**：共有設定を行う前に、アーカイブに機密情報を含むファイルが入っていないかを必ず確認してください。
> 共有する場合は、同じ演習に参加しているメンバーなど、共有して問題のない相手に限定してください。適切な相手がいない場合は、演習では共有を行いません。

## REFLECT — 振り返り

- Cowork が「関連ファイル」と判断した根拠は妥当だったか。人の目で見て漏れていたのはどれか
- 普段、同じ作業を手作業で行うとしたら、どの工程に最も時間がかかるか
- 移動対象を実行前に確認し、承認できたことで、誤ったファイルを移動する不安は減ったか
- HTML の振り返りページは、そのまま人に送れる品質だったか。足りなかったのは何か

**うまく動かない場合**
ファイルが特定されない場合は、プロジェクト名だけでなく、関係者名・期間・キーワードをプロンプトに追加してください。
移動が実行されない場合は、対象ファイルが他者所有の SharePoint ライブラリにないか（自分に編集権限があるか）を確認してください。
