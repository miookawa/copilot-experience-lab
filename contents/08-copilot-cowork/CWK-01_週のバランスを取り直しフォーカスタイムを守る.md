# 週のバランスを取り直し、フォーカスタイムを守る｜CWK-01

| 項目 | 内容 |
|---|---|
| **目的** | 断片化したカレンダーに振り回される前に、提案 → 承認 → 実行の流れで自分が主導権を握る |
| **所要** | 約 15 分（目安） |
| **利用** | Microsoft 365 Copilot Cowork（Outlook カレンダー） |
| **入力** | **自分の業務データ**：今週または来週の自分の Outlook カレンダー |
| **成果** | 週の会議サマリー → 承認付きの変更提案 → カレンダーへの反映（承認したものだけ） |

> **実施条件**：Copilot Cowork が利用でき、自分のカレンダーに数件以上の予定がある場合のみハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

> **クレジット消費の目安**：`[Light / Medium / Heavy から選択]`（`[要記入]〜[要記入]` クレジット）。この演習の手順を実行した場合の参考値です。実際の消費量は、対象データの量・形式・内容や、依頼する処理によって変動します。
>
> Light / Medium / Heavy の区分は、Microsoft の [Copilot Credits Guide](https://www.microsoft.com/licensing/guidance/Copilot-Credits) で使われている表現に基づきます。

---

## シナリオ

週の大半が会議で埋まり、資料を作る時間も、考える時間も取れない。
前日の夜に慌てて翌日の資料を作り、重複した会議は直前に調整する——これが多くの人の現実です。

Copilot Chat に「今週の予定を教えて」と聞くことはできます。
ですが **Cowork は、1 回の依頼を起点に、確認と承認を挟みながら作業を進められます**。会議の負荷を集計し、確認の質問を投げ、変更案を提示し、**あなたが承認したものだけをカレンダーに反映します**。

> **演習のポイント**：この体験の見どころは、出てきた予定表の内容ではなく、**「提案 → 確認 → あなたの承認 → 実行」という進み方そのもの**です。
> Cowork が勝手に予定を書き換えないこと、そして人が判断する場所がどこに置かれているかを確認してください。

> **進行役の説明例**：「Chat は答えを返します。Cowork は、あなたが承認した変更をカレンダーに反映します。勝手に書き換えるのではなく、実行前に確認と承認の段階があることを見てください。」

---

## TRY — 手順

1. Copilot Cowork を開く
2. 次のプロンプトを貼り付ける

```text
今週のスケジュールを整理するのを手伝ってください。
Outlookのカレンダーを確認してください。

まず、サマリーを表示してください：会議の総数と費やした時間、
フォーカスタイム（2時間以上）がどこにあるか、
そして会議が最も多い曜日。

変更を行う前に、確認のための質問をしてください：
私のマネージャーや上司の予定（会議に参加しているかどうか、参加者数）、
今週達成すべき目標、予定の重複時の優先順位付け、個人的な予定、
そしてどの会議を断るか、あるいは短縮すべきかなどです。

次に、説明付きで提案された変更を表示してください：
承諾／辞退／再調整する会議、
解決すべき競合（主催者へのメール送信を含む）、
追加するフォーカスブロック。
影響の大きい変更から先に示してください。

私が各変更を承認したら、カレンダーに1件ずつ直接編集を加えてください。
```

3. **送信**を選ぶ
4. 表示されたサマリーを確認し、続いて提示される質問に回答する
   - 選択肢やチェックボックスが表示された場合は該当する項目を選び、必要に応じて自分の言葉で補足します
5. 提案の一覧を読み、**実行してよいものだけ**を指定する（例：「3 と 5 だけ承認します」）
6. 承認した変更だけがカレンダーに反映されたことを Outlook 側でも確認する

> **安全に進めるためのヒント**：実データのカレンダーを変更したくない場合は、手順 5 で「実行はせず、提案一覧を Word にまとめてください」と指示してください。
> 提案 → 承認の型はそのまま体験できます。

## REFLECT — 振り返り

- 1 回の依頼から「サマリー」→「確認質問」→「提案」→「承認して実行」まで進んだことで、手作業はどれだけ減ったか
- Cowork の確認質問のうち、**自分が言語化できていなかった前提**はどれか
- Chat に同じことを頼んだ場合と比べて、**自分の手作業として残った工程**はどこか
- 来週、この一連の作業をもう一度任せるとしたら、最初のプロンプトのどこを変えるか

**うまく動かない場合**
カレンダーの予定が少なすぎると提案が薄くなります。対象期間を「今週」から「今月」に広げて試してください。
変更が反映されない場合は、自分が主催者でない予定の再調整が含まれていないかを確認してください。辞退に相手の承認は不要ですが、再調整には主催者による予定の変更が必要です。
