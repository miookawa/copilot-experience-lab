# 基準に照らして監査し、Excel で可視化する｜CWK-07

| 項目 | 内容 |
|---|---|
| **目的** | 複数ファイルをブランド ガイド・命名規則・社内基準に照らして監査し、重大度順のアクション リストにする |
| **所要** | 約 30 分（目安／Cowork の処理待ち時間を含む） |
| **利用** | Microsoft 365 Copilot Cowork（OneDrive / SharePoint / Excel） |
| **入力** | **自分の業務データ**：監査対象のフォルダー（**5〜10 ファイル程度**）＋ 基準を書いた資料 1 点<br>**サンプル ファイル**：[`cwk-07-audit-sample.zip`](https://github.com/miookawa/copilot-experience-lab/releases/download/cwk-07-audit-sample-ja-v2.0.0/cwk-07-audit-sample.zip)（監査基準 1 件＋監査対象 6 件） |
| **成果** | 重大度別の違反一覧 → 優先順位付きのアクション リストを含む Excel 監査レポート |

> **実施条件**：Copilot Cowork から対象フォルダーにアクセスできる場合のみハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。
> **演習時は対象ファイルを 5〜10 件に絞ってください。** 件数が多いほど処理時間とクレジット消費が増えます。

> **クレジット消費の目安**：`[Light / Medium / Heavy から選択]`（`[要記入]〜[要記入]` クレジット）。この演習の手順を実行した場合の参考値です。実際の消費量は、対象データの量・形式・内容や、依頼する処理によって変動します。
>
> Light / Medium / Heavy の区分は、Microsoft の [Copilot Credits Guide](https://www.microsoft.com/licensing/guidance/Copilot-Credits) で使われている表現に基づきます。

## シナリオ

ブランド表記のゆれ、命名規則の違反、古い製品名の残存、必要な注記の欠落。どれも一つひとつ確認できますが、数十ファイルを漏れなく確認するには、多くの時間と集中力が必要です。そのため、確認が行き届かず、公開後に見つかることもあります。

この体験では、1 回の依頼で、Cowork にフォルダー内のファイルを基準と突き合わせ、違反を重大度別に分類させます。さらに、問題・影響・推奨修正と優先順位をまとめた **Excel 監査レポート**まで作成します。
この演習で行うのは、監査とアクション リストの作成までです。元のファイルは変更せず、実際の修正作業は演習に含めません。

> **演習のポイント**：基準との比較から優先順位付きのアクション リストまでを、1 回の依頼で作成します。重大度で並べ替えることで、どの問題から対応すべきかを確認しましょう。

> **進行役の説明例**：「フォルダー内の複数ファイルを基準と照合し、問題・影響・推奨修正を Excel にまとめます。この演習では、修正作業に入る前の判断材料を作るところまで進めます。」

## TRY — 手順

1. 監査対象のフォルダーを決め、**5〜10 ファイル**に絞る（機密性の高い資料は避けてください）
   - サンプルを使う場合は、入力欄のリンクから ZIP をダウンロードして展開し、`audit-targets` フォルダーを OneDrive または SharePoint にアップロードします
2. 基準にする資料を 1 点決める
   - 自社のブランド ガイドライン、命名規則、文書作成ルールなど
   - サンプルを使う場合は、ZIP 内の `LST_MKT_コンテンツ品質基準_20260115_v3.2.docx` を `audit-targets` フォルダーの外にアップロードして使用します
3. Copilot Cowork を開き、次のプロンプトを `[ ]` を置き換えて貼り付ける
   - サンプルを使う場合は、`[フォルダー]` をアップロードした `audit-targets` フォルダー、`[ファイル／画像／アセット／ドキュメント]` を「ドキュメント」、`[私たちの基準／ブランドガイドライン／コンプライアンスポリシー／命名規則]` を `LST_MKT_コンテンツ品質基準_20260115_v3.2.docx` に置き換えます

```text
[フォルダー] 内のすべての
[ファイル／画像／アセット／ドキュメント] を
[私たちの基準／ブランドガイドライン／コンプライアンスポリシー／命名規則]
に照らして監査してください。
それぞれを全文読み込んでください。

違反を重大度ごとに分類してください：
重大（Critical）
大（Major）
小（Minor）

各違反について、問題、影響、
そして具体的な推奨修正を記述してください。

レビューした項目の総数、カテゴリ別の違反、最も多い問題、
そして対応すべき推奨順序を示す、
並べ替え可能な Excel レポートを作成してください。

ファイルは一切変更しないでください。アクションリストを提示してください。
```

4. **送信**を選ぶ
5. 生成された Excel を開き、重大度で並べ替えて**上位 3 件を今週の対応リスト**として書き出す
   - サンプルを使う場合は、上位 3 件の指摘を基準資料と監査対象ファイルに照らし、基準にない違反や重複計上がないかを確認します

## REFLECT — 振り返り

- Critical と判定されたものは、実際に Critical だったか。判定基準は自分の感覚と合っていたか
- 監査レポートから、どの指摘を優先して対応すべきか判断できたか。判断に足りない情報はなかったか
- 1 回の依頼でフォルダーの監査から Excel のアクション リスト作成まで進んだことで、手作業はどれだけ減ったか
- 自分のチームで、この監査を定期的に回すとしたら対象はどのフォルダーか

**うまく動かない場合**
違反が大量に出て使えない場合は、基準を絞ってください（例：「表記ルールのみ」「命名規則のみ」）。
読み込めないファイルが多い場合は、形式（PDF のスキャン画像など）を確認してください。
処理が長い場合は、対象ファイル数を減らしてから再実行してください。
