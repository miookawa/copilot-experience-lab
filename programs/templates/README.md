# プログラム雛形

新しいプログラムを追加するときは、このファイルをコピーして `programs/<program-name>/README.md` を作成してください。

> `README.md` は、パートナーや進行役が準備・運営するための文書です。エンドユーザー向けページが必要な場合は、同じフォルダーに `index.md` を作成してください。
> 体験の中身は `contents/` に置き、`programs/` 配下へコピーしないでください。

- **対象**：（誰向けか）
- **所要**：（約 90 分など。複数日にわたる場合は `期間` に変更）
- **ゴール**：（このプログラムで何を持ち帰るか）
- **位置づけ**：（他のプログラムとの違いや、このプログラムを選ぶ理由。必要な場合のみ）

## エンドユーザー向けページとの整合

`index.md` を作成する場合は、次の情報を `README.md` と一致させてください。

- 所要時間または期間
- 使用するデータ
- 体験の順序
- 必須・選択・発展の区分
- 体験カードの ★ 表示
