# プログラム雛形

新しいプログラムを追加するときは、このファイルをコピーして `programs/<プログラム名>/README.md` を作成してください。

> このファイルは**ポインタ + 順番 + ルール**だけを持ちます。体験の中身は `content/` にあります。
> **`programs/` 配下に content をコピーしないでください。**

- **対象**：（誰向けか）
- **所要**：（時間）
- **ゴール**：（このプログラムで何を持ち帰るか）
- **演出**：（チェックリスト / ポイント / バッジ / RPG / チーム戦 のいずれか）
