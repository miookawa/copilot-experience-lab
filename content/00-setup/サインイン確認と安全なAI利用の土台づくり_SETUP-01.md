# サインイン確認と安全なAI利用の土台づくり｜SETUP-01

| 項目 | 内容 |
|---|---|
| **目的** | 正しいアカウントで Copilot に入り、AI をどの信頼基盤の上で使っているかを理解する |
| **所要** | 約 10 分（目安） |
| **利用** | Copilot Chat / OneDrive / SharePoint |
| **入力** | 職場アカウント、Lakeshore サンプルデータ一式 |
| **成果** | 正しいアカウントでのサインイン、サンプルデータ配置、信頼基盤の理解 |

---

## シナリオ

Copilot の体験は、**個人アカウント／職場アカウント／Microsoft 365 Copilot ライセンス付きアカウント**のどれでサインインしているかによって見え方が変わります。
正しくサインインしておくことが、このセッションで意図した体験にたどり着く前提条件になります。

---

## TRY — 手順

### 1. Copilot Chat を開く

いずれかの方法で開きます。

- **方法 A — ブラウザー**：`copilot.cloud.microsoft` にアクセスする
- **方法 B — アプリ**：デバイスの Microsoft 365 Copilot アプリを開く

### 2. アカウントを確認する

1. 求められたら、ファシリテーターから配布されたアカウント、または自分の職場アカウントでサインインする
2. 左のナビゲーションで **チャット** が選択されていることを確認する
3. Copilot Chat のプロンプト ボックスが表示されていることを確認する
4. 使用中のアカウントを確認する
   - ブラウザー：左下のプロフィール画像またはイニシャルを選択
   - アプリ：プロフィール画像・イニシャル・アカウント名を選択（アプリの体験により左下または右上に表示）
5. サインイン中のメールアドレスが、セッション用アカウントまたは自分の職場アカウントと一致していることを確認する
6. 違うアカウントの場合は、**サインアウト／アカウントの切り替え／別のアカウントでサインイン**（表示名は環境により異なる）を選び、正しい職場アカウントでサインインし直す
7. Copilot Chat に戻り、職場アカウント・組織・保護を示すインジケーターが表示されているか確認する

### 3. Lakeshore サンプルデータを準備する

1. [**Lakeshore Retail サンプルファイル一式**](../assets/lakeshore-sample-data-ja.zip)をダウンロードし、展開する。
2. OneDrive または SharePoint を開く
3. `Lakeshore Retail Immersive Experience` という名前のフォルダーを作成する
4. 展開したサンプルファイルをアップロードする
5. 各ファイルを一度開いて、正常に開けることを確認する
6. このフォルダーは Section 2・3・4 で使うので、そのまま残しておく
7. **Outlook と Teams の演習では Lakeshore ファイルを使わない。** 自分の職場アカウントから、安全に要約できるメール スレッド／Teams チャット／チャネル スレッド／会議を 1 つ選ぶ

---

## 演習で利用する 3 つのデータパターン

| データパターン | 使う演習 | 意味 |
|---|---|---|
| プロンプト内完結 | Section 1 の各演習 | 必要な情報はすべてプロンプトに含まれている。ファイルのアップロードは不要 |
| Lakeshore サンプル | Copilot、Excel、Word、Analyst、Agent Builder の演習 | ファシリテーター提供の架空データ。指示されたら OneDrive / SharePoint にアップロードする |
| 自分の業務データ | Outlook、Teams、会議リキャップの演習 | 自分の安全なメール・チャット・チャネル・会議を使う。ダミーファイルは使わない |

> **プライバシー上の注意**：Outlook / Teams / 会議の演習では、**要約しても問題のない内容だけ**を選んでください。
> 機密情報、人事・法務・財務に関わる情報、個人情報、機微な顧客情報は使用しないでください。
> 要約結果をグループで共有する必要はありません。

## Microsoft 365 の信頼基盤

Microsoft は、組織が Microsoft 365 で既に依拠しているのと同じ信頼基盤 —— ID、アクセス許可、コンプライアンス、プライバシー、データ保護、責任ある AI —— の上で AI に取り組んでいます。

職場アカウントで Microsoft 365 Copilot を使うと、Copilot は Microsoft Graph を通じてユーザーの業務コンテキスト（ファイル、メール、予定表、チャット、会議、連絡先など）にアクセスし、関連性の高い応答を生成します。
Microsoft 365 Copilot ライセンスが提示するのは、**ユーザーが少なくとも閲覧権限を持つ組織データのみ**です。また、プロンプト・応答・Microsoft Graph 経由でアクセスされたデータは、**基盤となる大規模言語モデルの学習には使用されません**。

| 信頼の観点 | このラボでの意味 | 何を見るか |
|---|---|---|
| ID | Copilot の体験は使用するアカウントに紐づく。個人／職場／Copilot ライセンス付きで機能が異なる | プロフィール画像、イニシャル、サインイン中のメールアドレス、職場アカウント インジケーター |
| アクセス許可 | Copilot は既に持っているアクセス権の範囲内で動く。アクセスできないファイル・メール・会議・チャットは使われない | ファイル・会議・メールの参照、自分のアクセス権に紐づいた引用元 |
| コンプライアンス境界 | Copilot のやり取りは Microsoft 365 のサービス境界内に留まり、プライバシー・セキュリティ・コンプライアンスのコミットメントに沿う | 組織の保護インジケーター、Microsoft 365 アプリの体験、業務コンテキストに基づく応答 |
| データ保護 | プロンプト・応答・Graph データは基盤モデルの学習に使われない | Copilot Chat 上の職場アカウント／エンタープライズ データ保護インジケーター |
| 秘密度ラベル | 秘密度ラベルや文書取り扱いポリシーなど、既存の Microsoft 365 の保護は Copilot 利用時も引き続き有効 | Word、Excel、OneDrive、SharePoint 上の秘密度ラベル、保護された文書の表示、元ファイルの保護 |
| 監査とガバナンス | 組織の構成とライセンスに応じて、Copilot のやり取りはログ記録・統制の対象にできる | Copilot のアクティビティ履歴、保持設定、監査／eDiscovery、Microsoft Purview（有効な場合） |
