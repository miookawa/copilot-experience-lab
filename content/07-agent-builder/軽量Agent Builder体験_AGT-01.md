# 軽量Agent Builder体験｜AGT-01

| 項目 | 内容 |
|---|---|
| **目的** | 繰り返し業務を、指示を書いたエージェントとして固定する |
| **所要** | 約 20 分（目安） |
| **利用** | Copilot の Agent Builder |
| **入力** | Day 26 で選んだ繰り返し業務 1 件 |
| **成果** | 自分用の軽量エージェント 1 つ（インストラクション付き） |
> **実施条件**：Agent の作成・共有可否や利用できる機能は、管理者設定、テナント構成、ライセンスによって異なります。実施前に管理者またはライセンス専門家に確認してください。
> 作成できない場合は、ファシリテーターのデモを見ながらインストラクションの書き方だけを持ち帰ってください。

---

## シナリオ

[繰り返し業務を1つ選ぶ｜DAY-26](./繰り返し業務を1つ選ぶ_DAY-26.md) で決めた業務を、エージェントとして固定します。

候補としては、次のようなものが扱いやすいです。① 社内用語を維持した日英翻訳エージェント ② 会議メモを決定事項とアクションに変換するエージェント ③ ホワイトボード写真から構造化された資料案を作るエージェント ④ 社内の特定ガイドラインについて回答するエージェント ⑤ 定型文書をルールに沿ってレビューするエージェント。

以下は、③ を例にしたインストラクションの書き方です。

> 進行役の説明例：「エージェントの出来より、「推測させない」指示が書けているかを見てください。」

---

## TRY — 手順

1. Agent Builder を開く（利用可否は事前に管理者へ確認）
2. Day 26 で選んだ業務を 1 つ決める
3. エージェントの名前を決める
4. インストラクション欄をクリックする
5. 次のインストラクション例を貼り付け、自分の業務に合わせて書き換える

> **インストラクション例**

```text
あなたは会議ホワイトボード整理エージェントです。

ユーザーが提供したホワイトボード画像またはメモを読み取り、
次の順序で整理してください。

1. 会議のテーマ
2. 主なアイデア
3. 決定事項
4. 未解決事項
5. アクション項目
6. PowerPointのスライド構成案

読み取れない部分は推測せず「判読不能」と記載してください。
固有名詞や社内略語は勝手に展開しないでください。
```

6. エージェントを保存する
7. 実際の入力（写真、メモ、文書など）を渡して動かす
8. 推測して補完された箇所がないかを確認する
9. 指示を修正して、もう一度動かす
10. 共有可否を管理者ポリシーに沿って確認する

> **注意**：Agent の作成・共有可否や利用できる機能は、管理者設定、テナント構成、ライセンスによって異なります。公式ガイドでも、エージェントには利用可能な種類、共有ポリシー、管理設定があると案内されています。
